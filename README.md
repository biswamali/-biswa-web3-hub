# BISWA Web3 Personal Hub — v1

This is a polished first concept for BISWA: a personal Web3 identity hub rather than a conventional portfolio.

## Included
- Premium dark Web3 visual direction
- Responsive mobile/desktop layout
- Personal story / timeline
- Roles and collaborations
- Selected ecosystem work
- Content impact / tweet-analysis direction
- Proof vault using supplied screenshots
- Contact and social links
- Future-content editor demo using browser localStorage

## Important
The editor in this prototype is intentionally a demo. It is NOT a secure public admin system.
For the real production version, the next step is to connect the site to a private admin dashboard + database (e.g. Supabase) so BISWA can securely add/edit/delete achievements, projects, tweets, metrics, proof images and timeline events from anywhere.

## Run
Open `index.html` in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.

## Recommended production architecture
Next.js + Tailwind + Supabase + private admin dashboard + image storage.
