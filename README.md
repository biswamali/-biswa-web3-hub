# BISWA Web3 Hub v2

This version changes the site from a generic portfolio into a section-by-section personal Web3 identity site.

## Tweet showcase
Send BISWA's X post links. Each post can become a clickable case-study card containing:
- tweet screenshot
- views / impressions
- likes
- reposts
- replies
- bookmarks when available
- engagement rate when data is available
- context
- research angle
- why the post worked

The entire card opens the original X post.

## Important
This is the front-end v2. A real private admin dashboard + database is a separate production step. Do not put secrets in this static project.
